## 🎓 How to Use

### For Developers:

**Test the feature:**
```bash

open dermoscanners/client/VOICE_INPUT_TEST.html

# Option 2: Full app
cd dermoscanners/client
npm run dev
```

**Deploy to production:**
```bash
cd dermoscanners/client
npm run build
# Deploy dist/ folder as usual
```

### For End Users:

1. Open chatbot (blue button)
2. Click microphone icon 🎤
3. Allow microphone access
4. Start speaking
5. Watch text appear
6. Click send or edit first
